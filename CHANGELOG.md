# Changelog

See each release's Package.swift for the full range of compatible Prebid Mobile
versions; each entry below names the version it was certified with. Each release
supports any patch release of the certified Chartboost Monetization SDK minor version.

All official releases can be found on this repository's [releases page](https://github.com/ChartBoost/chartboost-prebid-ios-adapter/releases).

### 309.14.0
- Initial release of the Chartboost Prebid Mobile plugin renderer.
- This version of the adapter has been certified with PrebidMobile 3.4.0 and ChartboostSDK 9.14.0.
